# Matriz de Configuración Electrónica Interactiva

En esta actividad se implementa una matriz de configuración electrónica en forma de triángulo invertido, con la capacidad de personalizar el número de filas y columnas a visualizar.

## Instrucciones de uso
1. Clona el repositorio: `[https://github.com/Jsgarcia06/Matriz-de-configuraci-n-electronica`
2. Abre el proyecto en tu editor de código.
3. Ejecuta el archivo `index.html` en tu navegador favorito.
4. Elige la cantidad de filas y columnas que deseas ver.
5. Abre la consola para visualizar el resultado.

## Tecnologías utilizadas
- HTML5
- JavaScript
